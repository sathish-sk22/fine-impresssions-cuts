Drop your customer brand logo images into this folder:
e.g.
  public/customers/brand1.png
  public/customers/brand2.png
  public/customers/brand3.png

Then open `src/data/businessData.js` and set the `logo` property in `CUSTOMERS`:
  { id: 'c1', name: 'Brand Name', logo: '/customers/brand1.png' }

Supported formats: PNG (transparent recommended), SVG, WebP, JPG.
